# tCarKit 开发指南

## 页面与数据

`Home` 消费姿态、障碍物和方向轴；`Performance` 消费 4B 资源与延迟；`Vision` 消费视频、姿态融合、电池和 HUD。页面切换不能暂停后台遥测采集。

## 连接流程

```text
connect -> GET 192.168.66.1/test -> resolve Core host -> API/RPC/video
```

连接失败时必须保留页面运行，并显示可诊断的状态，而不是阻塞 UI 线程。

## 配置持久化

所有用户设置写入应用配置文件；非法值启动时忽略并回退默认值。调试面板、FPS、帧延迟和网络延迟开关均属于持久化设置。
